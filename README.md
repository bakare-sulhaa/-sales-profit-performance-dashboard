# -sales-profit-performance-dashboard
An interactive Excel dashboard analyzing sales, profit, and customer 
performance across regions, categories, and time periods.

## Overview
This project transforms raw retail sales data into an interactive 
dashboard using Excel Pivot Tables, Pivot Charts, and Slicers, allowing 
users to filter insights by Year, Category, and State.

## Key Insights
- Total Sales: 124.2K | Total Profit: 38.6K
- Michigan leads sales by state (66.6K)
- Customer count grew steadily from 2021 to 2024
- Sales peak in December, dip in February

## Tools & Skills Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)
- Data cleaning and structuring
- Dashboard design and data visualization
- KPI tracking and trend analysis

## How to Use
1. Download the Excel file from this repository
2. Open in Excel
3. Click the slicers (Year, Category, State) to filter the dashboard interactively
